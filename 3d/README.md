# キャンパス 3Dビューア

1. 電子棟のモデルを `3d/models/denshito.glb` に配置します。
2. OpenCampus フォルダでローカルサーバーを起動します。

   ```powershell
   python -m http.server 8000
   ```

3. `http://localhost:8000/3d/` から「電子棟」を開きます。

GitHub Pages などの静的ホスティングでも `/3d/denshito.html` から表示できます。
HTML をダブルクリックする `file://` での表示には対応していません。
Three.js と圧縮モデル用 Draco デコーダーを CDN から取得するため、インターネット接続が必要です。
Three.js 本体とアドオンは同じバージョン（0.180.0）に固定しています。

ドラッグで回転、ホイールまたはピンチで拡大縮小、右ドラッグまたは2本指で移動できます。
「視点をリセット」で全体表示に戻り、「自動回転」で建物の周囲を自動で回ります。
モデルの大きさと画面の縦横比に合わせて初期視点を自動調整します。

通常の GLB と Draco / Meshopt で圧縮された形状に対応しています。
KTX2 テクスチャなど、追加デコーダーを必要とする形式は未対応です。
